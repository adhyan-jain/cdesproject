A compiler that runs inside a fixed memory budget needs a symbol table whose size is fixed in advance, whose behavior at the limit is defined, and whose cost per call cannot be driven up by hostile source text. Textbook and production designs rely on an allocator and offer none of these properties. We present STRATA, a scoped symbol table that keeps an open-addressing index, packed identifier records and an undo stack in one caller-supplied buffer; a call that does not fit is refused and leaves the table unchanged. We prove that, for every open-addressing scheme that never moves keys, removing the newest key by clearing its cell is an exact undo, so the table always equals a fresh table of its live names, and that last-in-first-out order is the only deletion order safe for every table. On this basis the probability that a probe limit refuses a legitimate name is computed exactly: at load three quarters it lowers the limit for a one-in-a-million refusal probability from 455 to 258 probes, and it agrees with the implementation in 2.8 million trials. On events logged by a C compiler for eight projects, STRATA gives no wrong answer, needs a fixed buffer 16.4 to 17.9 percent smaller than a conventional single-buffer table, a saving an exact space ledger attributes to a stored hash word and name packing, and is indistinguishable in speed on six of eight traces. Colliding identifiers slow declarations 300-fold; a keyed hash and the probe limit remove the slowdown.

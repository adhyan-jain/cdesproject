# Overleaf project: IEEE Access manuscript

Main file: `main.tex`. Compiler: **pdfLaTeX**. Bibliography: **BibTeX** with `IEEEtran.bst`
(`references.bib`). Overleaf's default build (pdfLaTeX, latexmk) runs the passes needed.

Upload `strata_ieee_access_overleaf.zip` with *New Project > Upload Project*, or upload the
contents of this folder. Set the main document to `main.tex`.

Local build:

```
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Before submission

Search `main.tex` for `AUTHOR:`. Every hit is information only the authors can supply
(`../AUTHOR_DETAILS_REQUIRED.md`). The command `\authorfill` prints them in bold so that none
can be overlooked in the PDF. See `../reports/SUBMISSION_CHECKLIST.md`.

Packages used beyond the template's own example: `algorithm` (float for the pseudocode) and
`url`. Both are in every TeX distribution and on Overleaf.
